# Code of Conduct

We follow the Contributor Covenant v2.1 in short form:

- Be kind, patient and constructive. Many contributors and users here live
  with disabilities — accessibility and respect are not optional.
- No harassment, personal attacks, or dismissive behavior.
- Critique code, never people.

Report conduct issues to the repository owner via the contact details in the
README. Unacceptable behavior may result in removal from the project.
